# Step 13C.4 — Daily site progress

Reports are append-only in the public API and record observations, not authoritative task updates. Site engineers and project managers may submit for their scopes; owner/admin may submit across the organization. Finance may read reports in its report scope; contractors may submit/read their own observations for currently assigned site tasks with active company/project affiliation. Reports require valid site/project pairs and optional tasks at that site. Work dates use Dhaka calendar dates. Existing private sanitized site photos can be attached by their uploader; the attachment is moved to the report (one parent constraint). Report-owned photos are no longer in the general gallery and cannot be deleted through the media API. Private read URLs recheck report access. Contractor photo uploads are not supported yet. No migration or dependencies. Selector caps: 100 sites, 100 tasks per site, 48 latest site photos (filtered to own). No editing or deletion API, and no standalone detail route. Archived project/site records are not accessible via these views. Test fixtures remain in the isolated test database; the evidence fixture is metadata only, not an actual S3 object. Live storage, browser workflows, contractor integration, full typecheck, lint and production build require local verification. Remaining earlier blockers are not resolved here.
