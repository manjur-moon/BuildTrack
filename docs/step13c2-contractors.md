# Step 13C.2 — Contractor management foundation
Admin/owner only for company directory, profile and enrollment. Existing verified Better Auth members are linked, then company is assigned to a project, then an explicit worker project grant is created. Task assignment uses the existing task interface. No schema changes. Ending assignment, unlinking, or suspension revokes contractor grants; reactivation does not restore revoked grants automatically. Existing task records are retained. Associated task list is an operational reference, not historical attribution or a performance score. Worker transfers are not supported. Manual ID entry and limited profile lists are temporary. PM/finance scoped views, accurate historical attribution, full integration/HTTP security verification and construction idempotency hardening remain required. Integration fixtures remain in isolated buildtrack_auth_test. Do not use production or development databases.
