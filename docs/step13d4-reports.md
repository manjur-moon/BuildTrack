Reports: `/dashboard/reports`. Authorized project selection, financial report (posted amounts, twelve months through today), timeline (task and milestone deadlines, authoritative average), contractor outcomes (current project/company/task associations, distinct tasks per company). No new API endpoint: reports are server-rendered with per-request authorization.
